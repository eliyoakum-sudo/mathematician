Mathematician

An esoteric programming language

Tape based esolang

N (A number that sets what the plus or minus after it adds or subtracts from the cell)

+ (Adds to the cell according to the number behind it)

- (Subtracts from the cell according to the number behind it)

x (Next cell)

/ (Last cell)

= (Print ascii value)

Note: Numbers not followed by a + or - will not error but will not effect the code and should be used for stylization

Computational class: finite state machine

This includes: mathematician.html which is an interpreter
